# Lunix

> [!NOTE]
> This project is in very early WIP.

Lunix is a Linux-like operating system for the Nintendo 3DS that aims to run Linux stuff.

This project is inspired by [AuroraOS](https://github.com/TeamAuroraOS/AuroraOS) and Android3DS.

## Roadmap

| Feature | Status |
|---|---|
| Keyboard | Not implemented |
| Touchscreen | Not implemented |
| Shell | Not implemented |
| Linux application support | Not implemented |
